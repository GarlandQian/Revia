# 用户报错以结构化语义跨 IPC，在呈现层翻译

M6 增加即时切换的简体中文 / English 界面，既有 Rust 用户报错也须双语（Q164）。Rust 返回稳定错误类型和结构化参数，前端按当前语言生成文案，而不是通过 IPC 返回已拼好的中文或英文句子；这会带来一次跨模块契约迁移，但能让已有错误随语言切换正确呈现，避免按已翻译句子判断错误类别或把不同语言的文案混在同一界面中。

## Consequences

- “操作被拒绝 / Git 命令失败 / 环境问题 / 内部错误 / 结果待核对”等分类语义保留；详细原因也必须是可识别类型与参数，不能把原来的整段中文错误塞进参数规避迁移。
- 用户内容、路径等原始数据不翻译；Git 原始输出可作为详情保留。调试与测量日志不要求翻译。
- 验收从真实 Git 触发生产 Rust 错误，核对载荷并通过生产英文格式化链路断言用户看到的是英文，不能只检查错误码或以模拟后端代替（Q168）。
