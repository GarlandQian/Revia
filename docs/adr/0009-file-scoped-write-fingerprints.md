# M2 写操作的 diff 指纹按目标文件限定范围

M1 预留的是整个 worktree 的 diff 摘要，但在编辑器持续修改其他文件时，沿用这个摘要会频繁拒绝用户对未变化文件的操作。M2 的暂存、取消暂存和丢弃按操作涉及的文件及相关版本、状态和路径校验，无关文件变化不阻止操作；即使只操作一个 hunk，同一文件其他部分的相关变化也必须拒绝（Q80）。这是对 [ADR-0005](./0005-write-ops-carry-diff-fingerprint.md) 的范围补充，不取消执行前校验，也不以“补丁仍然能应用”代替版本一致性。

## Consequences

- 校验必须覆盖被允许写入的文件类型，不能因为未跟踪文件或二进制文件没有普通文本 diff 就绕过检查。
- 单个 hunk 仍受所在文件的相关状态约束，不只比较被选中的几行。
- M3 提交涉及的校验范围不由本决定自动推定，不能把单文件操作的范围直接套到整个提交上。
