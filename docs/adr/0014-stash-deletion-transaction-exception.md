# stash 删除事务的窄范围后端例外

2026-10-29，用户授权仅为 stash 单条删除和清空评估并验证 git2/libgit2 的持锁 reflog 事务，作为 ADR-0002 的窄范围例外。系统 Git 当前实现先按序号选择 reflog 条目，之后才持引用锁；临近再读和进程内互斥无法保证终端并发时仍删除已确认对象。其余 Git 操作继续通过 Rust 的系统 Git CLI 执行器。

该授权允许实施验证，不代表事务机制已经通过验收。删除须先完成独立归档，再在同一跨进程引用锁内核对目标身份及确认集合并修改 reflog/引用；不增加隐藏引用、不手写引用文件、不删别人的锁、不改用户配置。锁冲突、仓库格式不支持或身份不明时拒绝删除；提交回执不确定时保留归档并标记结果待核对，不自动重跑。真实 Git 并发、失败和恢复验证未通过前，入口保持拒绝删除，M6 不因此降低验收要求。
