# 被删除 stash 的完整回收内容保存在用户仓库之外

M6 删除或清空 stash 前，将条目的完整内容独立保存到 Revia 自己的回收区目录，保留 14 天；取回时恢复为原仓库 stash 列表中的条目，不直接改变工作区或暂存区（Q160）。不在用户仓库增加隐藏引用，也不依赖该仓库继续保留原对象；相比以引用或 reflog 留存，这会增加独立归档的存储与验证成本，但不会向其他 Git 工具的提交图中引入 Revia 私有引用，也不会因 Git 清理对象而失去回收内容。

## Consequences

- 归档必须包含取回条目所需的完整内容；只保存 OID 或补丁不满足本决定。Git bundle 是用户认可的示例形式，不限定最终存储格式。
- 原归属无法确认时不得把条目导入另一个仓库；不以路径相同推断仓库身份。
- 本决定增加 stash 类型的回收内容，不改变 [ADR-0010](./0010-recovery-records-preserve-worktree-state.md) 中普通文件恢复不改变暂存区的语义。
