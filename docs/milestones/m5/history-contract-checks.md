# 只读历史契约检查

本清单细化任务 01 的安全与数据一致性验收，不定义 Rebased 的产品默认值。来源：2026-10-27 对 `d58233c` 执行器、会话和 diff 管线的独立静态复核。

| 边界 | 可复现的检查 |
| --- | --- |
| Git 参数 | OID 参数中的 `--help`、`HEAD~1`、不存在对象和 blob OID 被拒绝；文件名 `--help`、`:(glob)*`、`a[1].txt` 按字面匹配。没有 shell 拼接仍须防 Git 选项/pathspec 注入 |
| 固定起点 | 读第一页后移动/删除分支或标签，旧分页仍读原 OID，新查询读新引用；缺对象报错，不退回当前 HEAD |
| 游标身份 | 分叉/合并、相同时间戳、非单调日期的历史以小页读取，无重复遗漏；游标跨仓库或关闭后拒绝，limit 有限额 |
| 父提交 | 返回全部真实父 OID；根提交不硬编码 SHA-1 空 tree；普通/双父/多父提交显式选父，无关父提交拒绝 |
| 固定文件 | 打开后修改工作区、暂存或切分支，不改变历史正文/布局/高亮；重命名左右分别读原路径，缺失一侧与空文件不同 |
| 路径身份 | 用 NUL 分帧的机器格式；换行、Tab、引号、反斜杠、前后空格不 trim；不可从显示 patch 的路径标题反推身份 |
| 非 UTF-8 | 两个不同字节路径即使显示名相同也不串读；合法 UTF-8 文件名中真实的 U+FFFD 不误判；不支持则明确不可打开 |
| 错误语义 | 空仓库、空提交、空 blob、缺对象、解码失败、Git 非零/超时分别处理；多行正文/分隔符不污染下一条提交记录 |
| 缓存隔离 | 同路径不同仓库、不同父项、不同空白选项不串缓存；容量受限；淘汰/释放后重取或拒绝语义明确 |
| 异步归属 | A 请求阻塞，切到 B 再释放 A，结果仍带 A 的身份；旧实例关闭后不能认领到新实例 |
| 关闭与释放 | close 幂等，旧目标立即失效；在途任务返回不能重新填充已关闭缓存；释放不声称立即杀掉所有 Git/高亮线程 |
| 只读副作用 | external diff/textconv 哨兵不运行，不隐式 fetch 缺失对象，不 checkout/reset 或写临时 index；前后 HEAD、refs、index、工作区和 Git 配置不变 |

复用风险：现有 `Git::file_at` 会吞错并有损解码；`ChangesKind`/`ChangeEntry` 带工作区语义；`release_session` 移除映射不等于取消已持有 Arc 的任务。它们不是现成的历史读取协议。
