## 1. 安装版：安装 / 启动 / 卸载 / 升级

- [ ] 普通用户双击 `setup.exe`，不出现管理员提权；安装完成可启动。
- [ ] 首次启动没有额外控制台窗口；主窗口有原生标题栏、最小化/最大化/关闭与系统菜单。
- [ ] 确认数据写入当前用户标准目录，不在 exe 旁创建 `data`。
- [ ] 关闭后重新启动，设置、仓库列表、提交草稿保留。
- [ ] 用同一版本重装（升级路径），确认不丢数据。
- [ ] 用更高版本安装包走应用内更新（见第 6 节），确认安装器退出应用后新版本启动。
- [ ] 卸载：确认程序移除；记录用户数据是否保留（按产品语义记录，不擅自删除用户数据）。
- [ ] 安装路径含空格 / 中文时仍可启动（安装到自定义目录时）。

## 2. 便携版：解压即用、改名、移动、失败与 WebView2

- [ ] 解压 zip，确认结构为 `Revia\Revia.exe`；直接运行 `Revia.exe` 可启动。
- [ ] 单独复制 `Revia.exe` 到另一空目录运行：仍启动，并在该目录创建 `data`。
- [ ] 把 exe 改名为 `Anything.exe` 后运行：仍按便携模式，数据仍在该目录 `data`。
- [ ] 把整个文件夹移动到另一盘符/目录后运行：设置、草稿、登录保留，数据跟随目录。
- [ ] 检查 `data` 下存在业务数据与 `webview2` 用户数据；不写用户目录、不写注册表
      （用 Process Monitor 或安装前后对比用户目录）。
- [ ] 把 `data` 目录设为只读 / 拒绝当前用户写入后启动：出现明确错误提示并退出，
      **不得**回退到用户目录或悄悄创建另一份数据。
- [ ] 在没有 WebView2 Runtime 的干净系统启动便携版：出现安装 WebView2 的明确指引并退出；
      不自动安装、不把运行时塞进 data。
- [ ] 便携版界面只提示新版本并提供“下载便携版”，没有下载/安装/重启按钮（见第 6 节）。

## 3. Credential Manager 与登录

- [ ] 安装版登录 GitHub（device flow 或 Token），关闭并重启：仍为登录状态。

- [ ] `cmdkey /list` 或凭据管理器可见 Revia 条目；`data` 目录内没有令牌/刷新令牌明文。

- [ ] 记录令牌轮换后仍能继续 API 操作（刷新流程）。

## 4. PowerShell、profile、hooks 与终端

- [ ] 安装 PowerShell 7；profile 中按 fnm 文档配置 `fnm env --use-on-cd`。
- [ ] 打开含 `.nvmrc` 的 worktree：内置终端 `node -v` 与 `.nvmrc` 一致；
      Git hook 中 `node -v` 也一致。
- [ ] 卸载/移走 PowerShell 7 后重启：回退到 Windows PowerShell，终端与 hooks 仍可用。
- [ ] profile 写入错误语句：应用显示诊断/回退提示，Git 操作仍能执行；
      不修改 profile 与执行策略。
- [ ] 把 profile 改为阻塞（如 `Start-Sleep 30`）：环境捕获在硬超时后回退并给出提示，
      应用不卡死。
- [ ] 终端起始目录为 worktree；`cd` 到含空格/中文路径正常；关闭运行中进程前有确认。
- [ ] 普通 Git 操作（状态、diff、暂存、提交、fetch）不额外弹控制台窗口。

## 5. 路径、换行与 Git 核心工作流

- [ ] 中文 + 空格路径仓库：添加、打开、diff、暂存/取消暂存、提交、丢弃、恢复均正常。
- [ ] CRLF 仓库（`.gitattributes` `eol=crlf`）：修改后暂存，`git diff --cached` 无额外
      换行改动；工作区字节保持 CRLF。
- [ ] 丢弃改动后文件恢复为提交时 CRLF，回收区含被覆盖内容；恢复后状态正确。
- [ ] 工作区 diff 编辑保存后仍为 CRLF；外部修改后保存被拒绝并提示。
- [ ] 真实 Git 操作使用系统 Git：手动指定 Git 路径、PATH 中的 Git 均可；
      找不到时提示手动指定，不改 PATH / Git 配置。
- [ ] 提交 hooks 正常执行；跳过 hooks 的选项仍可用；提交前快照与回收区语义不变。
- [ ] 锁占用、外部修改、结果待核对提示按既有行为工作。

## 6. 更新：安装版与便携版

- [ ] 稳定渠道：只收到稳定版；开启预发布后能看到预发布版本。
- [ ] 便携版：检查更新只显示版本/说明与“下载便携版”；点击打开对应 zip 下载地址；
      不调用安装器；直接调用下载/安装/重启命令被拒绝并提示。
- [ ] 安装版：下载后校验签名；确认安装前若存在未保存编辑、Git 写入或终端会话，
      先完成保存/等待/关闭协调，再启动安装器。
- [ ] 安装器退出应用后重启：新版本运行，更新回执显示“已安装”；未重启前显示待安装，
      不把安装器退出当作已确认。
- [ ] 取消安装器：仍为旧版本，界面保留待安装/可重试状态，不自动重装。
- [ ] 更新失败/断网：保留已下载包与明确错误，不重复自动安装。
