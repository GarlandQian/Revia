# 06：打开与切换仓库分段出内容

Status: ready-for-agent
Blocked by: 01

## What to build

切换仓库后先出界面和文件列表，日志、分支概览、进行中的操作、stash 等在后台补上，等待期间界面可以操作。见规格 D 节。

## Acceptance criteria

- [ ] 首屏取数拆成“文件列表优先”和“其余在后台补上”两段；后补内容出错时就地显示错误，不影响文件列表。
- [ ] 切走后迟到的结果不覆盖新仓库的界面（沿用 Q90 的旧响应处理）。
- [ ] 加载期间没有超过 100ms 的主线程阻塞，用任务 01 的分段耗时和长任务记录核对。
- [ ] `tools/fixtures/setup.sh` 用 `git fast-import` 新增大仓库 fixture：约 2 万个文件、3 万个提交、300 个改动文件；生成物不进版本库。
- [ ] 本机在 `diffs` 和大仓库 fixture 上记录第一次打开与切换的分段耗时，写进 report。0.3 秒门槛是否达到，由规划方在可见窗口复测确认；第一次打开的门槛还要等任务 05 完成。
