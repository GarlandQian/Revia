# 07：设置“AI”页与 AI 服务配置

Status: ready-for-agent
Blocked by: None（可立即开始；按 Q208 排在性能任务之后实施）

## What to build

设置的“提交”分类下新增“AI”页：填写服务地址、模型名、密钥和生成语言，并能改写提示词、恢复默认。密钥存系统凭据库，并与服务地址绑定。见规格 E 节。

## Acceptance criteria

- [ ] “AI”页照现有 Loop 式设置页写法，包括服务地址（带三个示例）、模型名、密钥、生成语言（跟随仓库、中文、English）、完整的默认提示词编辑区和“恢复默认”。
- [ ] 服务地址、模型名、语言、自定义提示词、已确认发送的地址存进 Revia 设置；密钥只存 macOS 钥匙串或 Windows Credential Manager（两种 Windows 形态都是），复用 GitHub 凭据的 `keyring` 写法，用独立的 service 名。
- [ ] 前端只能写入或清除密钥、查询是否已设置，读不到密钥原文；设置文件、日志、诊断信息里都没有密钥。
- [ ] 改了服务地址后，旧密钥从凭据库删除，界面要求重新填写；已确认发送的地址只对原地址有效。
- [ ] 服务地址或模型名为空即视为未配置，提供给提交信息框判断是否显示“生成”。
- [ ] 默认提示词写清：只输出提交信息、首行简洁、需要时写正文说明原因、参考最近的提交写法。固定规则（语言、首行上限、空行、只输出提交信息）不放在可编辑的提示词里。
- [ ] 新文案照 x18n 流程，中英文齐全。补凭据替身回归测试：写入、清除、改地址后删除旧密钥。
