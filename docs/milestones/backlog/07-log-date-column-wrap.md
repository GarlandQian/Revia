**Status:** done（M6 修复，2026-10-30 Release a187c87 桌面验收：中英文、默认窗口与 900 宽窗口日期单行，表头对齐）

## 背景

原因：`src/features/log/LogView.tsx` 中日期格固定 `w-[110px]`，没有禁止换行；11.5px 字号下这串文字加内边距约 110px，刚好放不下。
