# 12：切换仓库后首次读取完成前仍显示上一仓库的改动列表

**What to build:** 切换仓库或 worktree 后，在新目标的首次改动读取返回前，改动列表显示“读取中”，不继续显示上一个目标的文件。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 首次读取返回前不显示旧目标的条目，也不提供针对旧目标的操作入口
- [ ] 迟到的旧目标结果仍按现有代次规则丢弃
- [ ] 不影响同一目标刷新时保留选择和滚动

## 背景

M6 桌面验收（2026-10-30）C01：用验收接缝扣住 late-a 的 list_changes 时，late-a 标题下仍显示 tools 的改动列表；对这些行的操作确认框会写明原仓库 tools，不会写错目标，但容易误会。属于 M2 / M4 行为，不阻断 M6。
