## 实施顺序

1. **统一几何与测试。** 完善 `RowHeights` 的边界与分数位置互换，增加现有 Node 测试脚本。
   把左右对照的像素、显示行、文件位置换算抽成纯函数。文件位置统一为 0 基，保留行内比例；
   中线落在折叠占位时按相同折叠区映射，文件末尾的插入点允许位于最后一行之后。
   完成条件：空文件、首尾、不同换行高度、折叠、纯新增/删除和段边界都有明确计算结果。
2. **左右行高。** 父组件持有左右两份 `RowHeights`。缓存随显示行索引、软换行、字号、
   字体、栏宽、显示空白与内容快照失效；固定行高模式不因栏宽变化重建。
   每栏在布局阶段只测已渲染的数据行，折叠行保持固定高度。测量前保存可见位置，
   测量后恢复并刷新内容位移、滚动条、行号与色带，避免布局前移导致内容跳动。
3. **全部位置消费方接线。** 行顶部、行号、弧形色带、段按钮、同步滚动、改动跳转、
   handle 的内容高度/可见范围/覆盖判断，以及采样共用行高数据。
   跳到改动明确定位两栏，不依赖同步开关；同步误差使用与实际滚动同一套换算和首尾夹紧。
   宽度、字号、字体和显示空白改变后保留可见内容，不使用旧测量值。
4. **样式与统一视图复核。** 开启时内容行自动增高，文字可在任意位置折行；行号和按钮
   对齐首个显示行，折叠行与块标题保持单行。保留交接中统一视图实现，补齐共享几何
   发现的问题与字体变化后的失效处理。默认关闭时不改变既有外观。
5. **C15 清理。** 软换行代码完成后，按既有主题映射直接替换旧 CSS 别名，保留颜色值；
   App 按主题与字体、通知、页签、树多选、批量写拆 hook，保持旧响应门禁与写锁生命周期。
   不改变安全边界或已确认行为。
