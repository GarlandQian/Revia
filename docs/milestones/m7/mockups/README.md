# Liquid Glass 外观预览

这是 M7 第 1 步的独立设计稿，依据 Q189–Q191：Liquid Glass 外观、代码清晰度优先，设计阶段同时考虑 macOS 与 Windows。第一版被用户指出“很不协调”；第二版是修订提案，尚待用户反馈。产品源码尚未改动，也未接入 React Bits。

## 第二版：连续窗口材质与两平台外壳

[打开第二版交互预览](./liquid-glass-v2.html)。可直接在浏览器打开，切换 macOS / Windows、浅深色、100% / 125% / 150% CSS 缩放与降低透明度；设置按钮展开浮层，Escape 关闭，审阅按钮改变示例状态。

| 平台 | 浅色 | 深色 |
| --- | --- | --- |
| Windows | [浅色图](./liquid-glass-v2-windows-light.png) | [深色图](./liquid-glass-v2-windows-dark.png) |
| macOS | [浅色图](./liquid-glass-v2-macos-light.png) | [深色图](./liquid-glass-v2-macos-dark.png) |

本稿把顶栏、侧栏、编辑器与底栏连为一体，使用细分隔线和统一控件比例，去掉第一版各区域单独的圆角卡片与彩色光斑。代码底层保持不透明，与周边取同一色系；浮层单独表现悬浮层次。强折射仍是待实现和验证的目标，本稿 CSS 磨砂不能视为已经实现。

Windows 示意右侧窗口按钮、窗口内菜单、Ctrl 提示及 Windows 路径；macOS 示意左侧红绿灯和 ⌘ 提示。窗口按钮仅示意位置，不操作系统窗口。颜色用于比较材质，不替换已确认的四套颜色主题。

HTML 使用原创 CSS / SVG 与静态示例代码，复用 M4 已有的 Codicons、文件图标及工程已有的 JetBrains Mono 字体。图标原许可见 [M4 图标说明](../../m4/mockups/)，字体保留 [SIL Open Font License](./fonts/jetbrains-mono-OFL.txt)。不连接 Git、账号或产品 IPC；分支与文件均为示例，无效的业务入口只作布局示意。

2026-10-30 使用本机已有的 Chromium Headless 148.0.7778.96、独立临时浏览器上下文，只打开本机 docs 预览。末轮 16 组全部通过：

| --- | --- |

| Windows 浅深色 × 125% / 150% CSS 缩放，1440×920 | 4 |

- 字体、图标和图片加载成功，无页面或请求错误；平台、主题、审阅和浮层控制可用。
- 代码为 13px 逻辑字号，底层不透明，正文与行号不施加 `filter`；缩放时保留窗口的显示宽度，纵横向滚动可用。
- 窗口按钮、审阅与设置入口、浮层不越出窗口；工具条、侧栏和编辑器连续相邻。
- 示例代码的正文、关键词、字符串、函数、类型、注释和行号在正文及红绿底色上的计算对比度均不低于 4.5:1；普通浅色最低约 5.31:1，深色最低约 5.51:1。这不是任意导入主题或全部可访问性通过的证明。
- 降低透明度与强制颜色模拟下关闭背景模糊；已人工查看两平台浅深色、Windows 窄窗、125% 浮层、150% 及强制颜色和降低透明度截图。

首次脚本检查通过后，截图复核发现 CSS 缩放会额外缩窄窗口，已修正并补查缩放前后的窗口宽度，再完成上述末轮检查。首轮与末轮源码、检查脚本、精确命令、真实退出码、原始输出及截图均保存在 `/private/tmp/revia-m7-glass-v2-kfb5dh4o/`；末轮为 `check-H0qStI`，本目录四张第二版图片复制自该轮。

这些结果只证明独立设计稿。Windows 外观是在 macOS 上的 Chromium 中渲染，系统字体会回退；CSS 缩放和媒体模拟不代替真实 DPI、高对比度或透明设置。后续仍须在 macOS WKWebView 与 Windows WebView2 验证材质、滚动、字体、原生窗口操作和性能，见 [实现核对](../liquid-glass.md)。
