# 05：克隆并打开仓库

Status: ready-for-agent
Blocked by: None

## What to build

提供 URL、目标目录和高级选项，Rust 调用 Git 克隆，成功登记，取消 / 失败说明保留目录。

依据：规格 E；Q179、Q153。

## Acceptance criteria

- [ ] 指定分支、浅克隆深度、子模块可选；独立 argv 防命令 / 选项注入
- [ ] 不覆盖既有非空目录；取消或失败不自动删除残留，显示实际目标与状态
- [ ] 成功登记真实仓库并打开；进度和错误随当前语言呈现，延迟结果不切换到另一目标
- [ ] 传输使用既有凭据，需输入及时失败；自建 local remote 覆盖成功 / 失败 / 取消 / 子模块相关路径

## Validation

在生产入口和独占 fixture 中核对实际可观察结果；原始证据保存到交接指定目录。相关改动完成后集中验证，遵守本地验证规则。产品真实桌面由任务 14 统一完成。
