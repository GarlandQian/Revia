# 03：编辑工作区 diff 并恢复草稿

Status: ready-for-agent
Blocked by: None

## What to build

并排 diff 的工作区一侧可编辑、显式保存，草稿跨切换和重启保留，并纳入关闭与写前协调。

依据：规格 C；Q122、Q177、Q186、Q195。

## Acceptance criteria

- [ ] 普通安全文本可编辑，其他类型 / 过大文件和历史侧只读；统一视图提供同文件并排入口
- [ ] 生产 Rust 写入核验真实 worktree、路径类型、原内容和指纹，保留权限与既有换行 / 编码策略
- [ ] 外部变化保留两版并拒绝旧保存；磁盘失败、重读失败保留草稿、原目标与已知回执
- [ ] 切文件 / worktree / 语言 / 主题保留内容，关闭保存 / 放弃 / 取消，暂存 / 提交前处理相关草稿
- [ ] 真实自建 Git 验证保存、外部修改、重启恢复、权限与跨目标失败；不修改用户文件

## Validation

在生产入口和独占 fixture 中核对实际可观察结果；原始证据保存到交接指定目录。相关改动完成后集中验证，遵守本地验证规则。产品真实桌面由任务 14 统一完成。
