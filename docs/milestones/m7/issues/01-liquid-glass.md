Status: ready-for-agent

## What to build

让既有审阅与提交界面采用已确认的连续玻璃外观，覆盖窗口、按钮、工具入口、浮层与平台外壳。

依据：规格 A；Q189–Q192、Q199。

## Acceptance criteria

- [ ] 实际复用固定 React Bits 三个组件，保留完整许可；主提交按钮采用第四版的低饱和填充和清晰状态
- [ ] 代码、行号、增删标记清晰；布局密度、焦点、点击、弹层、拖动与滚动保持可用
- [ ] 浅深色、macOS / Windows 外壳与修饰键、减少透明度 / 动态效果及高对比度有明确处理
- [ ] 相关 build / 类型 / lint 通过；真实材质与 D06 交任务 14，不凭浏览器预览标通过

## Validation

在生产入口和独占 fixture 中核对实际可观察结果；原始证据保存到交接指定目录。相关改动完成后集中验证，遵守本地验证规则。产品真实桌面由任务 14 统一完成。
