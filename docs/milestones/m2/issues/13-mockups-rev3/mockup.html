Revia 界面效果图

按 Q107 照 Rebased（JetBrains 新版界面）的布局和外观重画。只覆盖 M2 已有的功能：仓库与 worktree 选择、变更列表三组、diff 与 hunk 操作、各类提示和丢弃确认。确认后按此实现，再实测 D06。

  • 布局：顶部主工具栏放仓库和 worktree 组件；左侧工具窗口图标条只有“变更”和“回收区”两项；“变更”工具窗口有一排图标按钮和扁平文件列表；右侧 diff 编辑区有文件标题、差异导航、视图下拉和文件级操作；底部状态栏显示当前路径。
  • 外观：岛屿面板、JetBrains 新版界面的浅色和深色配色、Inter 与 JetBrains Mono（随应用打包）；diff 按 JetBrains 配色，新增绿、删除灰、修改蓝。
  • 沿用已确认的行为：文件名不上色，右侧单字母标状态（Q31）；已审阅勾选在行右侧（Q37）；未跟踪一组默认收起（Q30）；hunk 头保留“暂存此 hunk／丢弃此 hunk”。
  • 不新增功能：没有提交区、Shelf、历史和设置页；diff 只有一个文件标签，不做多标签（Q16）。
  • diff 行高保持 18px 不变，虚拟滚动和 D06 的测量方式都不受影响。

尺寸与密度

主工具栏 40px，图标条 40px 宽，工具窗口标题 34px、图标工具条 30px，文件行 24px；编辑区标签 36px、diff 工具条 32px；状态栏 24px；diff 正文 12px JetBrains Mono、行高 18px（与现在相同）。

字体

Inter 与 JetBrains Mono 都是 OFL 许可，随应用打包，离线可用；中文回退到系统字体（苹方、微软雅黑）。

颜色

界面配色取 JetBrains 新版界面 Islands Light／Dark；diff 新增绿、删除灰、修改蓝；状态字母按 JetBrains 文件状态色；提示条按信息、警告、错误三种底色。

窗口外观

macOS 红绿灯放在主工具栏左端；Windows 的窗口按钮在右端（Q60）。平台相关代码集中在平台模块（Q55）。

不变的部分

键盘行为、选择衔接、焦点不穿透、提示出现的位置、文案来源（i18n）和 Git 调用都不改；只调整按钮位置和外观。
