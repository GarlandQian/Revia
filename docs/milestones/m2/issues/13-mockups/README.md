## 覆盖的状态（任务 13 要求）

- **工具栏**：红绿灯融入工具栏、分支 chip、分栏/统一分段控件、图标按钮；**不含** Git 版本与文件数，**不含** A−/A+（任务 12 已删除）。
- **侧栏头部**：半透明材质（`backdrop-filter`）、仓库与 worktree 列表、系统强调色作选中色。
- **文件列表与分组**：未暂存 / 未跟踪（默认收起，只显示数量）/ 已暂存；状态字母用 Git 状态色（M/A/D/U/?）；右侧审阅勾选框。
- **diff 区**：18px 行高、等宽字体、gutter 行号、新增/删除行背景。
- **hunk 操作**：hunk 头部右侧的描边按钮（暂存 hunk / 丢弃 hunk），不用大面积色块。
- **各类提示**：
  - 空文件（新增文件没有内容）
  - 二进制文件（无法显示文本 diff）
  - 默认收起（未跟踪组）
  - 只读（符号链接 / 子模块 / 冲突 / 非 UTF-8）
  - 冲突（`U` 字母 + 只读徽标）
  - 操作被拒绝（文件已变化）
  - 结果待核对（顶部独立提示条）
  - 自动刷新不可用（顶部独立提示条）
