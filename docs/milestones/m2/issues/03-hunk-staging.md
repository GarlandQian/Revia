# 03：明确目标的 hunk 暂存与取消暂存

**What to build:** 开发者在并排或统一 diff 中，通过某个 hunk 的明确按钮只暂存或取消暂存这一段，其他 hunk 和工作区保持原样。

**Blocked by:** 02

**Status:** ready-for-human

依据：[M2 规格](../spec.md)实现决策 2、3、7，T02、T05、D02；ADR-0004、ADR-0009，Q81、Q89、Q93。

- [x] 操作使用与显示相同的 Git hunk，保留原始补丁语义，不从渲染行重新计算差异。
- [ ] 按当前变更组显示“暂存此 hunk”或“取消暂存此 hunk”，按钮可键盘聚焦和激活；整文件快捷键不改成 hunk 动作。
- [x] 只支持能力矩阵中的普通文本，不把二进制、仅权限变化或重命名提供为 hunk 操作。
- [x] 同文件部分暂存、多 hunk、增加／删除、无末尾换行与换行符场景操作正确，工作区及不相关内容／权限不变。
- [x] 即使选中 hunk 未变，同文件其他相关变化也拒绝；刷新后旧 hunk 目标失效，不按新快照中的同序号继续执行。
- [ ] 真实 Git 验证通过，两个 diff 视图中的操作结果与实际暂存区一致。
