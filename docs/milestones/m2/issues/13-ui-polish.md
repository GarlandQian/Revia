# 13：界面美化

**What to build:** 在已确认的 UI 方向内，把 M2 完成后的现有界面做成 macOS 原生质感、信息密度适合开发工具的样子，浅色、深色都成立，且不影响 diff 性能。

**Blocked by:** 03, 04, 05, 06, 07, 08, 12

**Status:** ready-for-agent

依据：[M2 规格](../spec.md)实现决策 9、D06、D08；[UI 方向](../../../ui-direction.md)；Q15、Q16、Q31、Q99、Q100、Q103、Q104。

- [ ] 动手前先出浅色、深色静态效果图，覆盖工具栏、侧栏头部、文件列表与分组、diff 区、hunk 操作、各类提示（空文件、二进制、默认收起、只读、冲突、操作被拒绝、结果待核对、自动刷新不可用）；经用户确认后再实现，确认的效果图留存在任务目录。
- [ ] 视觉参照 macOS 系统应用（Finder 侧栏、Xcode 导航、Mail 工具栏）：系统字体、系统强调色作选中色、细分隔线、图标按钮；信息密度参照 Fork；颜色只表达 Git 状态（Q15、Q31）。
- [ ] 侧栏半透明：实现后实测 D06，不退化才保留；否则使用接近系统侧栏的不透明颜色，并在报告中写明数据。
- [ ] 只改现有界面的外观、排版和交互细节，不提前实现提交区、worktree 侧栏、历史、设置页、命令面板、原生菜单栏等尚未排期的功能（Q100）；已确认的键盘行为、选择衔接、焦点不穿透和提示位置不变。
- [ ] 文案仍集中在 i18n；平台相关的窗口外观集中在平台模块（Q55）；Windows 编译不受影响。
- [ ] D06 实测不退化（首屏、两种跳转、两种视图快速滚动），浅色、深色真实桌面截图与确认的效果图一致。
- [ ] 类型检查、lint、build 与完整 Rust 测试通过。
