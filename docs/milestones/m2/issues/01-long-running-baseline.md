# 01：长期运行基线与必要修复

**What to build:** 在添加 M2 写入能力之前，证明当前正式应用同进程持续使用 30 分钟可用；复现到卡死或内存持续增长则先修复，未复现则保留真实长测证据。

**Blocked by:** None

**Status:** ready-for-agent

依据：[M2 规格](../spec.md)实现决策 1、D01、D06；Q53、Q78、Q84。

- [ ] 使用 release 构建、可见窗口、固定文件和 worktree，同一进程连续切换文件、视图并滚动 30 分钟；短测循环启动不算。
- [ ] 记录 Rust 主进程与相关 WebView 的内存，区分热身与之后的趋势；不卡死且热身后不持续增长。
- [ ] 发现问题先定位并修复后重测；没有复现时报告写“未复现，长测通过”，不猜测根因或写“已修复”。
- [ ] 必要诊断或修复不破坏现有首屏、跳转、高亮与滚动表现，不把独立偶发慢帧纳入门槛。
- [ ] 报告保留构建版本、可见窗口证据、负载、起止时间、操作记录与内存趋势；不能只报一个峰值。
- [ ] 若实施方不能完成真实桌面长测，提供可运行方法和已有证据，标为 `ready-for-human` 交规划方完成；实际通过前不开始后续任务。
