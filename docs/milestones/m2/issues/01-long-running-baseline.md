**修复**（`a29ec4a`）：`nextTask` 与 `nextPaint` 共用一条长期存在的 `MessageChannel`（与 React 调度器相同），`nextPaint` 的兜底时序不变。修复后同样计数：`MessagePort` 4→4、`JSEventListener` 173→173。单项诊断：switch 0.46、open 0.18 MiB/分钟。
