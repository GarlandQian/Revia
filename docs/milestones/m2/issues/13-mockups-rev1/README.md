## 相对原稿的修正

首轮复核指出原稿越出 M2 范围，并且把不同能力混在一张图里。修订如下：

1. **移除尚未排期的结构**：
   - 删除 worktree 侧栏列表（保留当前 M2 已有的「仓库与 worktree 由工具栏下拉选择」入口说明）；
   - 删除「历史」页签（只留「变更」）；
   - 删除提交按钮（提交区未排期），只保留审阅进度。
2. **默认收起的组不再展示子项**：未跟踪组只显示数量与一句说明，不再同时列出文件。
3. **只读文件不带可写 hunk 按钮**：选中的只读文件，diff 区 hunk 头部显示「只读：符号链接，不能暂存或丢弃」，没有暂存/丢弃按钮。
4. **各类状态分开展示**：新增独立状态区，每种状态只展示它真实具备的能力——空文件、二进制、默认收起、只读、冲突、操作被拒绝、结果待核对、自动刷新不可用。
