Revia 界面效果图

只改现有界面的外观和排版：仓库与 worktree 选择、变更列表三组、diff 与 hunk 操作、各类提示和丢弃确认。没有新增提交区、历史、worktree 侧栏或设置页。确认后按这一版实现，再实测 D06，决定侧栏是否保留半透明材质。

  • 跟 macOS 26 起的系统应用一致：侧栏浮在窗口里，红绿灯放进侧栏顶部，工具栏用胶囊按钮和分段控件。
  • 选中行用系统强调色。其他颜色只给 Git 状态字母、diff 的增删底色，以及提示条里的一个小图标。
  • 文件行：文件名用正常颜色，所在目录灰色跟在后面；右侧依次是改动行数、状态字母、已审阅勾选。悬停时行数换成暂存按钮。
  • diff 行高保持 18px 不变，虚拟滚动和 D06 的测量方式都不受影响；语法配色改为 Xcode 风格。
  • 提示不再用整条彩色横幅，改为 diff 区顶部的圆角提示条；文件级提示放在 diff 区中央，带一个图标和一句说明。

实现要点

确认后按这些数值实现；需要实测的项目在报告里写明数据。

尺寸与密度

列表行 24px，分组标题 11px；工具栏 52px；diff 正文 12px SF Mono、行高 18px（与现在相同）。字号仍用 ⌘+／⌘− 调整。

侧栏材质

用窗口原生半透明材质（NSVisualEffectView），实现后实测 D06；如果首屏、跳转或滚动退化，改用不透明的 #f1f1f4／#2a2a2e。

颜色

强调色跟随系统设置。状态字母 M／A／D／R／U／? 各一色，浅色、深色分别调过对比度；提示条只有图标带颜色。

窗口外观

红绿灯位置、标题栏覆盖和侧栏材质集中在平台模块（Q55）；Windows 用同一套布局，平台外壳按 Q60 另行处理。

不变的部分

键盘行为、选择衔接、焦点不穿透、提示出现的位置、所有文案的来源（i18n）和 Git 调用都不改。
