# 领域文档

本仓库是单一领域：根目录一个 `GLOSSARY.md`，加上 `docs/adr/`。

## 开始探索前先读

- `GLOSSARY.md`：领域术语。
- `docs/adr/`：与要改动的部分相关的架构决策。

## 使用术语表的说法

输出中提到领域概念时（任务标题、重构建议、假设、测试名），使用 `GLOSSARY.md` 中定义的术语。术语表里还没有的概念，要么说明在用项目不用的说法，应该换掉；要么说明术语表确实缺了，记下来交给 /domain-modeling。

## 指出与 ADR 的冲突

输出与现有 ADR 矛盾时，明确写出来，不要悄悄推翻，例如：

> _与 ADR-0004（hunk 一律来自 Git）冲突，但值得重新讨论，因为……_
